
# 001 no macro counter

The reference counter contract, from the stylus-sdk repo. Uses checked math for the
operations. Does not use the macro to derive the accessesors for the storage or for the
entrypoint, to serve as a test to ensure that we don't exceed this in the generated code.

Should not exceed 6403 bytes! wasm-opt output puts the binary at 3938 bytes. The reference
(with Stylus SDK, 0.90.2, no std, "z" optimisation level) codebase is 16598 bytes, and
with wasm-opt, 11441 bytes. This might be too generous, considering the reference uses the
default math to perform this operation, which would implicitly use the wrapped operation
in release. With wrapping math, the code generated by bobcat without wasm-opt is 6584
bytes.
